# Feature Info Multi

Feature Info Multi is a custom widget for ArcGIS Experience Builder that displays pop-up information from multiple map features at a selected location.

## Features

- Retrieve feature information from map clicks
- Configure the message action on Search widget to send selected results to Feature Info Multi
- Support Feature Layers and Map Image Layer sublayers
- Display multiple feature results in one panel
- Zoom to and highlight selected features
- Clear results, highlights, and map markers

## Requirements

- ArcGIS Experience Builder Developer Edition 1.21
- ArcGIS Maps SDK for JavaScript 5.1

## Installation

Copy the widget folder to:

```text
client/your-extensions/widgets
```

Restart the Experience Builder client, then add **Feature Info Multi** to your app.

## Configuration

Open the widget settings and select the Map widget to use.
